I am an engineering student with a dual passion for building seamless user interfaces and exploring the logic behind intelligent systems. My strength lies in taking complex backend architectures and giving them a beautiful, intuitive frontend face.

* 📱 **Mobile & Web:** Crafting cross-platform applications using **Flutter** and dynamic web interfaces with **React.js & Tailwind CSS**.
